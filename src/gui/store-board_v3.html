Note: quantity figures are simulated demo data until the AIoT gateway (board → cloud) is wired to the same Firebase feed the sensors will write to. Invoice PDFs are read locally in the browser with pdf.js (no AI, nothing leaves the page); because invoice layouts vary, the auto-filled fields are best-effort guesses — always check them in the review popup before saving. The "Estimated" courier timeline is derived from each courier's historical average lead time, not a live scan; the "Check live status ↗" link on each shipment opens the courier's own tracking page for the real, current status. Wiring in a courier's official tracking API would need a business/API account with that courier plus a small backend to call it from (browsers can't call most courier APIs directly).
